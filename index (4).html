❓ Ajuda - Como Usar o Sistema

Siga o passo a passo abaixo para configurar e utilizar a Caderneta Digital corretamente.

PASSO 1

📚 Cadastrar Turmas

Antes de cadastrar alunos, é necessário criar as turmas. Cada turma deve ter:

  • Ano/Série: Ex: 1º Ano, 2º Ano EM, etc.
  • Turno: Matutino, Vespertino, Noturno ou Integral.
  • Identificador (opcional): Letra para diferenciar turmas (A, B, C...).

Como fazer:

  1. Clique na aba 📋 Cadastro.
  2. Clique no botão 📚 Turmas.
  3. Preencha os campos do formulário.
  4. Clique em ➕ Salvar Turma.
📋 Exemplo: "1º Ano - Matutino - A" ou "2º Ano EM - Vespertino"
PASSO 2

📖 Cadastrar Disciplinas

As disciplinas são associadas às notas e frequências. Cadastre todas as matérias que serão avaliadas.

  • Nome da Disciplina: Ex: Matemática, Português, História.
  • Sigla (obrigatório): Ex: MAT, POR, HIS.

Como fazer:

  1. Clique na aba 📋 Cadastro.
  2. Clique no botão 📖 Disciplinas.
  3. Preencha os campos do formulário.
  4. Clique em ➕ Salvar Disciplina.
📖 Exemplo: "Matemática" (MAT) ou "Língua Portuguesa" (POR)
PASSO 3

👨‍🎓 Cadastrar Alunos

Os alunos devem ser vinculados a uma turma existente. Cada aluno precisa de:

  • Nome Completo: Nome do aluno.
  • Data de Nascimento: Data de nascimento do aluno (opcional, mas recomendado).
  • Turma: Selecione a turma em que o aluno está matriculado.
  • Status: Ativo, Desistente, Reprovado ou Transferido.

Como fazer:

  1. Clique na aba 📋 Cadastro.
  2. Clique no botão 👨‍🎓 Alunos.
  3. Preencha o nome do aluno, data de nascimento, selecione a turma e o status.
  4. Clique em ➕ Salvar.
👨‍🎓 Exemplo: "João Silva" - Nascimento: 15/03/2010 - Turma "1º Ano - Matutino - A" - Status: Ativo
PASSO 4

📊 Utilizando as Ferramentas

Após cadastrar turmas, disciplinas e alunos, você pode usar as ferramentas:

  • 📋 Notas por Turma: Lançar notas de todos os alunos de uma turma em uma disciplina e bimestre.
  • ✅ Frequência: Marcar presença ou falta dos alunos por disciplina e data.
  • 📋 Boletim: Visualizar o boletim individual ou resumo da turma.
  • 📝 Planejamento: Registrar planos de aula com status (pendente, em andamento, concluído).
  • 📚 Conteúdo Diário: Registrar o conteúdo trabalhado em cada aula, vinculado à turma e disciplina.
📊 Exemplo: Lançar notas do 1º bimestre de Matemática para a turma "1º Ano - Matutino - A"
💡 DICAS

Dicas para Melhor Uso

  • Ordem recomendada: Turmas → Disciplinas → Alunos → Notas/Frequência.
  • Exportar/Importar: Use os botões no cabeçalho para fazer backup ou transferir dados.
  • Tela Cheia: Pressione F11 ou clique no botão ⛶ para melhor visualização.
  • Refresh Automático: Os dados são atualizados automaticamente a cada 5 segundos.
  • Clique no logo PHD: Abre o sistema em uma nova guia para facilitar o acesso.
  • 🎂 Aniversariantes: O sistema alerta automaticamente sobre alunos que fazem aniversário hoje.
  • 🏷️ Status do Aluno: Utilize os status para controlar a situação do aluno (Ativo, Desistente, Reprovado, Transferido).
  • 📚 Conteúdo Diário: Registre o conteúdo de cada aula vinculado à turma e disciplina para consulta posterior.
  • ☁️ Firebase: Sincronização automática em tempo real.
  • 🔄 Sincronização Manual: Clique no botão "Sincronizar" para forçar a atualização dos dados com o Cloud.
